# Renderforge 1.6.3

- **Fix: geoscape cutscenes (e.g. the Disciples of Anu intro) could stall or lose most of their frame rate while the Crisp Geoscape markers overlay was on.** A Workshop report: the first Disciples of Anu cutscene froze (frames stopped, audio went on; fine with the mod off). When the game plays a geoscape cutscene it pauses object rendering by clearing the geoscape camera's culling mask; the marker overlay read that empty mask as "markers hidden", put its layer bit back, and the game stripped it again next frame -- a release / re-activate flap every other frame, each round scanning every site on the globe (about 1,260 cycles in a 55 s cutscene, 27-34 fps instead of 130-170). The overlay now stays released for as long as the game keeps object rendering paused and never writes onto a mask it does not own. Verified: 0 flaps, cutscene at 134-159 fps, the overlay re-arms after the cutscene ends (1440p, RTX 5070 Ti).
