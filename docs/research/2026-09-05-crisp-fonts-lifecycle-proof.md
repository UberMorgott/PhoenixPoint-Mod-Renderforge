# Crisp fonts lifecycle hardening and live proof

## Changes

- Retry allowance now follows the actual installed `TextGenerationSettings` equality contract plus its `generateOutOfBounds` field and text content. Density, font/size/style, best-fit limits, color, wrapping, extents and pivot changes renew the one-shot allowance. Atlas serial changes alone do not renew it. Glyph mapping and UV math are unchanged.
- Disable snapshots all owned Text references before clearing generators. It rebuilds those captions even if they now have custom materials or no longer meet the support policy. `Graphic.material` only dirties materials, so filtering the restoration by current eligibility was insufficient.
- The installed `CanvasUpdateRegistry.InternalRegisterCanvasElementForGraphicRebuild` refuses registration during graphics rebuild. Cleanup and pending vertex refresh therefore defer while layout/graphics rebuild or correction is active; the host survives until that work drains. No layout getter or global density setting is overridden.
- A late foreign Text mesh patch is checked at most once per dirty frame. Correction suspends and restores its affected texts; removal touches only its own three method patches. A user can enable the option again after the conflicting owner is removed.
