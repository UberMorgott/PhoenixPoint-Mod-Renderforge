# Guarded crisp fonts integration

- `Options → Screen → Crisp fonts` / `Настройки → Экран → Чёткие шрифты` uses the existing Apply/cancel flow. Default is enabled. Turning it off restores normal text meshes; it does not restart the renderer, NR or frame generation.
- The production core follows the [render-only density proof](2026-09-05-font-render-only-proof.md): keep the installed Text generator, preferred layout, positions, colors and all non-UV attributes; transfer only matching private density2 glyph UV0. Line/character/quad counts, hinted/best-fit size, box dimensions, orientation and rich-text colors must agree. Unsupported mappings use fresh original UVs.
- `CrispFonts` accepts exact `UnityEngine.UI.Text`, dynamic fonts, the default UI material and a root ScreenSpaceOverlay canvas. Bitmap fonts, Text subclasses, custom materials and world/camera canvases are excluded. Existing downstream UI mesh modifiers retain Unity's normal order. A foreign `Text.OnPopulateMesh` Harmony owner present at activation refuses the feature.
- Harmony owner `com.morgott.Renderforge.crisp-fonts` patches only Text mesh generation, OnDisable and the font setter. Disable removes only these owned patches and the font event callback. Private generators are released when Text disables, its font changes, or the option/mod disables. No diagnostic fixtures, watchdogs, font files, textures or packages ship.
- Font callbacks can synchronously reuse Unity's shared VertexHelper. The core copies the original vertex data before higher-density generation, guards nested correction and reruns the installed original path if the atlas changed. Pending event work causes at most one extra vertex refresh per cached text/content; there is no per-frame dirty/layout loop. Unity's shared font atlas may remain larger after disabling.
