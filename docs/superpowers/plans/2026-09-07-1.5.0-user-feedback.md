## Track C — Levels / Contrast / Clarity in the analytic post pass (ReShade parity)

- Post pass = native HLSL compute in `native/Sharpen.cpp` (`kColorGradeHlsl`), one dispatch; cbuffer packed by `FillSharpenConstants`.
- New stage order: RCAS → Grade(LUT) → Stylize → **Levels → Contrast → Clarity** → ColorVision (compensation stays last).
- Knobs (Options > Graphics, live, all default = off): Black point 0–40 (0), White point 215–255 (255), Contrast 50–150 (100),
  Clarity 0–100 (0). Levels: `c = saturate((c - black/255) / ((white - black)/255))`. Contrast: `(c-0.5)*k+0.5` in luma.
  Clarity: luma unsharp with a 12–16-tap Poisson blur sampled from the input SRV, radius ≈ 10 px × (H/1080), luma-only.
- Plumbing per knob (clone LUT strength): `DlssConfig` field + `[ConfigField]`, panel slider (LutPanel pattern), `SaveConfig`,
  `Dlss_SetFrame`/new `Dlss_SetGrade` ABI in `Native.cs` + `Device.h` + `RenderforgeNative.cpp`, cbuffer floats, `strings.csv`
  (4 labels + 4 tooltips, Codex translates, opus reviews), README table, DESIGN.
- Acceptance: in-game screenshots per knob at both extremes; pixel stats (mean luma / stddev) move in the expected direction;
  HUD pixels unchanged; frame time delta at 1440p reported.
