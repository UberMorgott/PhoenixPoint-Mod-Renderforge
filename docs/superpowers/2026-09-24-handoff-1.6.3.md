## 1.6.3 contents

- **Marker overlay stays released while the game pauses object rendering** (`2386807`, `src\GeoMarkerOverlay.cs`).
  Workshop report: the first Disciples of Anu geoscape cutscene froze (frames stopped, audio went on; mod off = fine).
  `UIStateGeoCutscene.EnterState` -> `CameraManager.PauseObjectRendering=true` -> GeoscapeCamera `cullingMask=0`; the
  overlay gate read mask 0 as "hidden", `Restore()` re-added bit 15 (mask `0x8000`), the game's `Activate` stripped it
  next frame -> release / re-activate flap every other frame (630 + 631 cycles in a 55 s cutscene, each
  `FindObjectsOfType` over 425 sites + Sync component add/destroy + command-buffer move; 27-34 fps vs 133-169 with
  the overlay off). Fix: the gate checks `PauseObjectRendering` ("object rendering paused by the game (cutscene)"),
  `Restore` never writes onto mask 0 or a mask someone else rewrote. After: 0 flaps, 5 marker log lines total,
  134-159 fps in the cutscene, overlay re-arms after exit (`0xFFFFFFFF -> 0xFFFF7FFF`, 195 fps geoscape). The
  freeze itself never reproduced on our rig (before or after); the mechanism is gone. Repro: console
  `play_cutscene DA_Intro_Cutscene` on a live geoscape.
- Version bump `7439e20` (+ `docs\release-notes-1.6.3.md`); smoke `a1a1b3a`. Locale descriptions untouched: they
  carry no changelog section and the "Crisp Geoscape markers" bullet is still accurate.
