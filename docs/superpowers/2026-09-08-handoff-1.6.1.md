## 1.6.1 contents

- **Pixel-perfect UI on by default** (`e74e43e`): `Canvas.pixelPerfect` on root overlay canvases + UI textures pinned
  to mip 0 (`MipBias.UiPin`, `CurrentUiBias = min(dlssBias, log2(canvasScale))` = -0.585 at 1440p under the 4K
  reference; -1.0 at 1080p). `Sprite_Create_Patch` (`src\Patches.cs`) pins textures mods create after the last sweep.
  Removes the 1 px edge line on runtime-created mod icons (`docs\research\icon-bleed-2026-09-08.md`). A saved
  `PixelPerfectUi:false` stays off.
- **Zero-z-scaled icons no longer vanish** (`e232220`): `Graphic_GetPixelAdjustedRect_Patch` falls back to the
  unsnapped rect when `PixelAdjustRect` returns an empty one (vehicle class icon, hotkey badges, AP pips).
- **Codex review fixes** (`5549b98`, `cx -Review -Base v1.6.0 -Deep`): (1) UI pin re-swept 0.5 s after any
  `Screen.width/height` change in every driver state (`DlssDriver.Update`, `lastScreenW/H`) — before, with the
  upscaler Off the pin stayed stale until the next level; (2) `Sprite_Create_Patch` honours `MipBias.Skip` (lut /
  noise / dither / ramp / gradient) so a late texture the sweep skips is never pinned and turning the pin off
  restores everything. Third finding (diag `IconBleed.cs.txt` mode sequencing) = research tooling only, not shipped.
- Version bump `1461b65`; smoke `d934b48`; descriptions rewritten in 8 locales `ac17f8d` (5.4–7.0 KB each, no BOM,
  no `[color]`, tags balanced).
