# Renderforge 1.6.1

- **Pixel-perfect UI is now on by default** -- besides snapping the interface to the pixel grid, it keeps interface textures at full resolution. Icons that other mods create from PNG files at runtime (TFTV's icons, for example) no longer show a bright 1-pixel line along an edge. Textures created later by other mods are covered as they are created. Turn it off under Options > Screen; a previously saved Off stays Off.
- **Fix:** interface elements shipped with a zero Z scale -- the vehicle class icon in the tactical squad bar, hotkey badges, weapon-enabled icons and action-point pips -- now draw normally with Pixel-perfect UI on, instead of vanishing.
- **Install:** use the single Full ZIP as before; restart once after updating.
