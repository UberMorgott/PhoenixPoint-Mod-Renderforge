## Lifecycle findings and next bounded proof

1. `AddonsManager` is plain C#, not a Unity object. Discover live `IAddonsManagerProvider` components; deduplicate managers; enumerate `RootAddon`, including the chassis. A `SetupRig` postfix must seed already-created visuals before subscribing to later changes.
2. A dead visual can retain `VisualsSourcePrefab`. Live hair change left `VisualRoot=null` with the old `Hair_SYN1_F_V01_Ready` prefab still assigned. Inventory separates `lastSourcePrefab` from `liveSourcePrefab` (null without a root). Never draw cached renderers after `AddonVisualsDestroying`, and do not use `AddonVisualsDestroyed` to look up the old root: it is already cleared.
3. Roster switching is asynchronous: a 500 ms delay yielded the previous head on some switches. No universal settled gate was established. For a mask, accept only current non-null visual roots after `AddonVisualsCreated` and current actor/manager generation agreement; invalidate during rebuild. A time delay alone is not proof.

Observed shader candidates: `Hidden/Internal-Colored`, supported, one pass, `_Color,_SrcBlend,_DstBlend,_ZWrite,_ZTest,_Cull,_ZBias`; `Unlit/Color`, supported, one pass, `_Color`; `Unlit/Colored Cutout`, supported, one pass, `_MainTex,_Cutoff,_Color`. These are inventory findings, not verified shader semantics or cutout contracts. Inspect/test each selected pass before using it as an exact mask.
5. Actual roster rendering camera is `GeoscapeCamera`, instance `300730`, deferred, reversed Z, 2560x1440, `allowMSAA=False`, target `DLSS color`, target MSAA 1, **target depth bits 0**. The other camera `DlssPresent` has culling mask 0. `DlssDriver` copies built-in depth to RFloat before image effects; this sampled texture is not automatically a writable depth attachment. The next proof must establish the correct scene depth attachment or explicit depth comparison, preserve occluders, and demonstrate that draw output excludes UI/scenery/eyes/hair.
6. After that, render the fixed skin submesh and one ordinary skin submesh into diagnostic targets using exact observed definitions/prefabs/renderer paths. Unknown variants fail open.
